DOCUKIT - DOCUMENTACION CON UN SOLO CLIC
========================================

Que es DocuKit?
DocuKit es una herramienta que documenta automaticamente
cualquier proyecto con solo hacer doble clic.

Como se usa?
1. Copia la carpeta "DocuKit/" dentro de tu proyecto.
2. Abre "DocuKit/scripts/" y elige tu perfil:
   disenador.bat   - Para artistas/ilustradores
   escritor.bat    - Para escritores
   desarrollador.bat - Para programadores
   generico.bat    - Para cualquier otro proyecto
3. Responde 5 preguntas (opcional)
4. Listo! Tu proyecto queda documentado.

Que archivos se generan?
- Reportes/BITACORA_PROYECTO.md (documentacion completa)
- Reportes/DOCUFY_DATA.json (datos estructurados)
- Reportes/RESUMEN_PROYECTO.txt (resumen rapido)

Alternativa visual:
Haz doble clic en "DocuFlow.hta" para una interfaz grafica.

Requisitos:
- Python 3.x instalado en el sistema
- Windows (tambien funciona en Mac/Linux con python3)

Para personalizar:
Edita "docufy_engine.py" y agrega mas tipos en CONFIG.
